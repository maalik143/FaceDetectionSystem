# FaceDetectionSystem - AI Face Detection Tool

YOLOv8-powered face detection and extraction tool with OSINT integration.

## Features
- Real-time face detection using YOLOv8 nano model
- Face extraction and saving to Scanned_Faces/
- OSINT face matching capability
- Fast detection (YOLOv8 nano - optimized for speed)

## How to Run
Double-click: run.bat

## Requirements
Install dependencies first:
`.
pip install -r requirements.txt
`

## Output
Detected faces are saved to: Scanned_Faces/
- Extracted_Face.jpg - Detected face
- Target_Face.jpg    - Reference face

## AI Model
Uses YOLOv8n (nano) - 6.2MB neural network
Provided by Ultralytics (ultralytics.com)

## Notice
Use for authorized purposes only. Face data is stored locally.
